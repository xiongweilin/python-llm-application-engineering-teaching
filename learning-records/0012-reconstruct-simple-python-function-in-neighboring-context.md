# 在相邻场景中独立重建简单 Python 函数结构

用户在不查看前两个示例文件的要求下，根据自然语言说明独立写出一个完整可运行的 Python 程序：定义两个变量，定义带两个参数的 `needs_heating` 函数，用 `<` 和 `if` 判断，分别 `return True` / `return False`，调用函数，把返回值赋给变量并用 `print` 输出。用户在运行前正确预测 `True`，运行结果一致，并能按“变量 → 定义函数 → 调用函数 → 返回值 → 赋值 → 打印”解释执行过程。

这构成了对已介绍语法的一次相邻迁移与独立重建证据。它不证明已经掌握循环、列表、异常、类或 bounded retry，也不证明在延迟后仍能保持该能力。
