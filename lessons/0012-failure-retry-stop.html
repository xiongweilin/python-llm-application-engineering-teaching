现实任务：一个操作可能成功、暂时失败或永久失败。暂时失败可以再次执行，永久失败必须立即停止；如果还有下一次执行机会，程序才会等待。

attempt · [代码变量] 执行序号当前正在执行第几次 operation()；第一次执行是 1，第一次重试是 2。
max_attempts · [代码变量] 执行次数上限整次操作最多执行多少次，包括第一次执行；不是“最多重试几次”。
delay · [代码变量] 等待时长如果还有下一次执行机会，两次执行之间等待多久；本题使用抽象时间单位。
TemporaryError · [程序概念] 可恢复失败标签这类失败允许进入“是否还有下一次”的判断。
PermanentError · [程序概念] 不可恢复失败标签这类失败立即停止，不进入等待分支。
sleep_fn(delay) · [Python 语法] 函数调用括号内的参数是等待时长；它只在确定还要执行下一次时调用。
关键边界：“是否等待”由停止条件决定；“等待多久”由等待策略决定。策略可以算出候选值，但最后一次失败没有下一次执行时，不会产生等待调用。

Python 写法这里先怎么理解
def f(...):定义一个函数；冒号后缩进的代码属于函数体。
operation传进来的另一个函数；它是一个可调用对象。
operation()现在执行这个函数。
sleep_fn传进来的等待函数；把它作为参数是为了记录和测试等待行为。
return x把结果交出去，并结束当前函数。
if a == b:如果两者相等，执行下面缩进的代码；== 是比较，不是赋值。
for ... in ...:重复执行下面缩进的代码；每轮会得到一个新的序号。
range(1, 4)依次产生 1、2、3；右端 4 是停止边界，所以不产生 4。
max_attempts + 1因为 range 不包含右端点，所以要加 1 才能让上限本身出现。
try:先尝试执行下面缩进的代码。
except X:如果出现 X 类型错误，执行这个分支。
raise把刚才捕获的错误继续抛出去。
class X(Exception):定义一种新的异常类型；继承 Exception 让它进入 Python 异常机制。
缩进表示哪些语句属于函数、循环、try 或某个 except 分支。

class TemporaryError(Exception):  # 创建“暂时失败”这一种异常类型，供下面的 except 精确识别
    pass  # 类体不增加额外行为；pass 是真实语句，不是待填写的练习空位

class PermanentError(Exception):  # 创建“永久失败”这一种异常类型，表示不能继续尝试
    pass  # 同样保留最小异常定义，让类型名称承担分类作用

def run_with_retry(operation, max_attempts: int, sleep_fn):  # 把操作、执行上限和等待函数组合成一个完整工作单元
    if max_attempts < 1:  # 先拒绝无效上限，避免调用者传入没有意义的执行预算
        raise ValueError("max_attempts 必须至少为 1")  # 这是调用参数错误，不属于可恢复业务失败
    for attempt in range(1, max_attempts + 1):  # attempt 是当前执行序号，从第一次执行的 1 开始
        try:  # 每一轮先尝试一次 operation
            return operation()  # 成功就立即返回，不再进入后续轮次
        except PermanentError:  # 永久失败没有恢复价值，直接把原错误交给调用者
            raise  # 保持错误类型和停止行为，不执行等待
        except TemporaryError:  # 暂时失败才允许进入重试判断
            if attempt == max_attempts:  # 最后一轮失败时不存在下一次执行
                raise  # 直接结束，不调用 sleep_fn
            sleep_fn(1)  # 当前示范使用固定等待策略：每次真正要重试前等待 1 个时间单位

class TemporaryError(Exception):
    pass

class PermanentError(Exception):
    pass

def run_with_retry(operation, max_attempts: int, sleep_fn):
    if max_attempts < 1:
        raise ValueError("max_attempts 必须至少为 1")
    for attempt in range(1, max_attempts + 1):
        try:
            return operation()
        except PermanentError:
            raise
        except TemporaryError:
            if attempt == max_attempts:
                raise
            sleep_fn(1)

fetch_with_retry

class AuthenticationError(Exception):
    pass

def fetch_with_retry(fetch_data, max_attempts: int, sleep_fn):
    if max_attempts < 1:
        raise ValueError("max_attempts 必须至少为 1")
    for attempt in range(1, max_attempts + 1):
        try:
            return fetch_data()
        except AuthenticationError:
            raise
        except TimeoutError:
            if attempt == max_attempts:
                raise
            sleep_fn(2)
