第 2 步 · 抽象的底层逻辑

状态转换是一条受限制的变化规则

现在只做：沿着流程读一遍，重点理解“转换是部分定义的”。
对象一个后台任务
当前状态waiting
事件start
下一状态running
概念 1

状态压缩了有关过去的信息

程序不需要每次重放任务的全部历史。它用当前状态表示“哪些过去事实与下一步决定有关”。例如 done 表示任务已经完成，因此再次 start 可能造成重复执行。

概念 2

事件不是状态

状态回答“现在处于哪里”；事件回答“刚发生了什么”。running 是状态，finish 是事件。二者共同决定下一状态。

概念 3

转换规则不是对所有组合都有答案

只有被业务明确允许的组合才有下一状态。表里没有 done + start，不是“还没想好”，而是这个组合不属于允许路径。

概念 4

稳定条件：实际变化必须属于允许集合

无论以后增加多少状态，稳定结构都是：读取当前状态与事件、查允许规则、找到就返回、找不到就停止。

δ(current_state, event) → next_state
δ 只对允许的组合有结果；没有结果的组合必须拒绝。

这里的 δ 读作“转换函数”，只是给规则取的符号，不要求背公式。关键是：同一组输入应产生一个确定结果，而不是由程序临时猜测。

第 3 步 · 具体的 Python 细节

抽象结构怎样落到对象、语句和控制流

现在只做：把每一行 Python 与上一页的底层结构对应起来。
def next_state(current: str, event: str) -> str:
    transitions = {
        ("waiting", "start"): "running",
        ("running", "finish"): "done",
        ("running", "fail"): "failed",
    }
    key = (current, event)
    if key not in transitions:
        raise ValueError(f"不允许的状态转换: {current} + {event}")
    return transitions[key]
函数与局部名称

current 和 event

调用函数时，两个实参分别绑定到函数内部的局部名称。类型标注 : str 表达接口意图，但 Python 默认不会仅凭标注自动拒绝错误类型。

Python 对象模型

字符串、二元组和字典

(current, event) 创建一个二元组。二元组不可变，里面的字符串也不可变，因此它可以作为字典键；字典把这个复合键映射到下一状态字符串。

控制流

if ... not in ...

程序先检查键是否存在。存在时跳过 raise，继续执行 return；不存在时进入分支并抛出异常，函数立即中断，不会再执行后面的返回语句。

接口约定

ValueError 与返回值

有效组合返回新的状态字符串；组合不被允许时抛出 ValueError。这个函数只作决定，不修改数据库或外部对象，因此调用者能先验证决定，再选择是否写入。

有效路径的执行顺序

1 输入waiting, start
2 建键(waiting, start)
3 查表键存在
4 跳过不抛异常
5 返回running

非法路径的执行顺序

1 输入done, start
2 建键(done, start)
3 查表键不存在
4 抛异常ValueError
5 停止不执行 return
容易混淆的地方：这不是递归，也没有修改原字符串。函数创建二元组和字典等对象，沿条件分支执行，最后返回字符串或抛出异常。

第 1/7 步 · 定向

本会话中文术语

这些词只服务于“状态与允许行动”。先按中文意思理解；英文和代码标识用于识别源码。

对象 object
被程序观察或处理的事物；本会话中是一项后台任务。
状态 state
对象当前所处的位置，也是后续行动能否发生的条件。
事件 event
刚刚发生、可能触发状态变化的事情，例如 start。
状态转换 state transition
对象从当前状态进入下一状态的一次受规则限制的变化。
转换表 transition table
明确列出哪些“当前状态 + 事件”组合被允许，以及它们对应的下一状态。
转换函数 transition function
接收当前状态和事件，返回下一状态或拒绝非法组合的规则。
部分函数 partial function
只对部分输入组合有结果的函数；没有定义结果的组合必须被拒绝。
二元组 tuple
把两个值按顺序放在一起的不可变对象；这里用作复合字典键。
字典 dict
保存“键 → 值”映射的 Python 对象；这里把复合键映射到下一状态。
成员判断 membership test
用 in 或 not in 检查某个键是否存在。
控制流 control flow
程序语句实际执行、跳过、中断和返回的顺序。
异常 exception
正常返回无法表达当前结果时，用来中断并向调用者报告问题的机制。
值错误 ValueError
输入类型可能正确，但值或值的组合不符合当前接口约定。
类型标注 type hint
写给人和工具看的接口提示；Python 默认不会只靠它自动强制类型。
