# Practice

This directory is intentionally sparse.

Practice artifacts should be created only for an active learning need. Prefer one current runnable work unit over a catalog of prewritten exercises.

A useful practice artifact should provide enough reality contact to test the target capability, for example:

- a behavior contract;
- a small code base or function boundary;
- tests, fixtures, logs, or a reproducible failure;
- explicit constraints when an external side effect or authority boundary matters.

Do not commit a full answer key before the learner has attempted the task. Remove obsolete generated exercises when their evidence has already been captured in `learning-records/`.
