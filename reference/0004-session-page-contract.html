学习会话页面规范

这份规范保证所有页面使用同一个最终目标、路线坐标、页面身份和证据边界。它是页面设计说明，不是需要完成的课程内容。

统一路线坐标

唯一最终能力事实源 → 阶段 → 学习环 → 正式会话 → 三个不同问题及各自步骤 → 本会话中文术语 → 可选参考卡

“第几课”和 HTML 文件编号只作为文件名或历史记录，不表示当前学习顺序。每页必须显示统一最终目标和当前位置，并能进入完整路线、最终能力摘要与唯一最终能力事实源。

正式会话必须包含

  1. 统一最终目标摘要，以及“阶段 → 学习环 → 正式会话”的当前位置；
  2. 通常三个不同问题；每个问题各有一个中心能力、明确边界和独立通过证据；
  3. A“专注隧道”式单步显示，一次只有一个当前动作；
  4. 每个问题完整经过七步：定向、底层逻辑、具体编程或计算细节、预测、核心实现、条件变化后的迁移、问题小结；
  5. 每个问题包含预测、核心实现、迁移三个任务，各有独立网页反馈；三个问题的正式会话共有九个任务；
  6. 一次会话级综合提交，不按题打断对话；
  7. 页面下方的“本会话中文术语”，只收录理解当前会话必须用到的词；
  8. 指向总术语表、完整路线、最终能力摘要和唯一最终能力事实源的链接；
  9. 本地保存、失败说明、来源和能力证据边界。

其他页面身份

综合复习会话

连接已有学习记录；不自动新增记录，也不推进正式进度。

已完成复习页

只查看某项证据细节，不再使用旧课次充当路线坐标。

候选参考页

尚未进入或等待重写，必须声明未来阶段、环和会话。
