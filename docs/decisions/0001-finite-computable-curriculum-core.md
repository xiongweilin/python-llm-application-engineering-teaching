# 0001：主线采用有限表示、有限维、可计算优先

## 状态

已接受，2026-08-03。

## 背景

原课程能够支持可靠的 LLM、RAG、工作流和 Agent 工程，也提供较宽的数学物理与模型训练入口；但从“LLM 应用 → Agent → 人机合作 → 有限机制分析”的长期目标看，概率决策、序贯决策、因果评估和机制验证之间缺少连续主轴。若直接追加完整概率论、强化学习、因果推断和机制设计，又会使四阶段、十七环失去最小性和可完成性。

## 决定

主线改为优先使用有限概率空间、有限状态与行动、有限类型博弈、有限容量和任务集合、有限维连续优化，以及可以枚举、求解、仿真或数值核验的模型。

课程保持四阶段、十七环：环 5 形成信念，环 7 完成受约束的单步选择，环 8 完成跨时间选择，环 9 分析多主体规则，环 14 把策略接入权限与人工容量，环 15 判断系统变化是否造成真实效果。数学物理与一般化理论从毕业主线移入研究扩展。

主线毕业能力命名为“有限机制分析与实现”，不声称已经掌握一般 Bayesian mechanism、Myerson 理论或复杂算法机制设计。

阶段 C 同样采用主线/扩展边界：计算图、基本优化器、数据划分、基础曲线判断、数值稳定和粗粒度资源估算属于主线；系统 LoRA、混合精度、深入量化、精细显存、完整调参与预训练研究按需扩展。LoRA 的矩阵结构和参数量可以进入主线，但不要求系统微调实验。

最终项目的序贯和机制证据允许使用与同一现实问题相连的离线有限模型、仿真或回放；只有实际接入运行系统的部分承担持久状态、权限、故障注入和回滚要求。这样保留统一问题链，而不把强化学习或支付机制部署变成隐含毕业条件。

## 未采用的方案

- 保留数学物理主线并继续追加决策课程：容量继续膨胀，责任边界不清。
- 先完成实分析、测度论和严格随机过程再进入 Agent：理论更完整，但会阻塞当前项目牵引的应用路线。
- 只保留 Agent 工程、完全删除正式决策与机制模型：无法支撑人机合作和规则设计的长期目标。

## 后果

- `FINAL-CAPABILITY-CONTRACT.md` 仍是唯一毕业能力事实来源；环级责任只由 `reference/0002-course-progress.html` 持有。
- 最终能力中的每个能力域必须在完整路线中对应明确的强制关口证据；“主线知识”中出现术语不等于关口已经覆盖，简短关口句只作摘要，覆盖索引才是完整证据清单。
- 主线中的计算结论必须标注有限范围和假设；穷举与仿真不能冒充一般证明。
- 振动、波、连续场、一般测度概率、高级强化学习、复杂因果识别和高级机制设计保留为研究扩展，不再成为主线毕业关口。
- 环 15 在主线内承担有限因果 DAG 的背门路径、碰撞点、后代、d-separation 与调整集判断；完整 do-calculus 仍属于研究扩展。
- 阶段 C 的扩展内容和离线序贯/机制证据必须显式标记，不能被派生摘要重新写成统一毕业要求或生产部署要求。
- 阶段 A 已完成和正在进行的学习记录不受影响；重构只改变尚未生成的后续课程与最终综合项目要求。
