# 0007：阶段 A 以完整工程工作单元为教学单位

## 状态

已接受，2026-08-18；取代 0002 中“每个正式会话保留三个不同问题、每题固定七步”的当前架构表述，并扩展 0006 的非回显与语义类型规则。

## 背景

近期教学反馈显示，学习者可以解释单行代码、识别局部语法并完成局部检查，却仍然不能把这些片段压缩成一个完整函数或完整诊断过程。旧页面把 retry、防重复、批处理三个模式放进同一正式会话，再为每个模式安排固定七步和局部任务，降低了每个动作的局部压力，却没有给任何一个完整模式留下足够的整体获得、重建和迁移时间。

“完整程序”也不是所有后续能力的共同形状。traceback 诊断、模块调用链和测试定位的核心产物可能是一个完整工作过程，而不是一个新函数。因此新的单位必须同时覆盖完整代码、完整诊断、完整调用链和完整修复回归。

## 决定

阶段 A 的基本教学单位改为：

> 一个完整、可观察、可验证的工程工作单元。

一个正式会话原则上只围绕一个主要工作单元，目标体量约 30–45 分钟。会话内的三个任务不再是三个互不相关的问题，而是同一工作单元的三类能力证据：

1. **模式获得**：完整范例、运行轨迹、完整模仿和渐进撤除帮助后的完整重建；
2. **受控变化**：在学习者自己的完整结构上只改变一个规则，先预测再运行，说明稳定部分；
3. **迁移与组块化**：在新情境或真实项目中识别稳定骨架、可变参数、边界和责任块。

每个工作单元统一采用：

```text
最小基础包
→ 完整范例与运行轨迹
→ 完整模仿
→ 完整重建
→ 受控变化
→ 新情境迁移
→ 稳定骨架与可变参数抽取
```

学习证据按 `R/T/P/M/D/X` 分开记录：识别、追踪、重建、修改、诊断、迁移。完整模仿和自动检查只能作为过程证据，不能单独推进能力关口。

数量、状态变量、程序结构和函数接口分别使用适合自身类型的说明模板；继续/停止与副作用值、策略候选值与实际运行值必须分开。预测必须先于运行验证，迁移必须标注 Level 1–5 的结构距离。

## 未采用的方案

- **继续“三个不同问题 × 固定七步”：**会话会反复接触局部片段，却没有足够时间形成任何一个完整 schema。
- **把所有题都改成手写完整程序：**诊断、调用链和回归工作单元不一定以新函数为核心；这会把教学单位错误地绑定到代码产物。
- **完全取消局部编辑：**局部编辑仍是阶段 A 的有效证据，但它必须发生在学习者已经拥有的完整结构上，并逐步撤除定位帮助。
- **用完整模仿或自动测试代替掌握：**这会再次把视觉复制或 checker 通过误判为完整结构获得。

## 后果

- 当前正式会话 2 改为一个 retry 工作单元，三个任务分别是模式获得、受控变化、迁移与组块化；防重复和批处理的历史记录不删除，后续分别安排完整工作单元。
- `SESSION-PAGE-CONTRACT.md` 不再规定每个正式会话固定 23 步、三个不同问题或九个任务；页面仍保留单步聚焦、帮助菜单、运行验证和统一提交。
- 阶段 A 后续页面需要先确定工作单元的完整行为和观察证据，再选择代码编辑、诊断、调用链或测试操作；不能为了填满固定任务数而拆散一个结构。
- 页面导航在点击步骤后定位到活动内容顶部；不再无条件滚动到整个页面上方。
- 每 2–3 个正式会话加入无答案间隔回忆，以检查结构是否能被压缩成骨架或责任地图。

## 影响的旧决策

- `docs/decisions/0002-guided-teaching-before-independent-transfer.md` 保留为“示范优先、局部修改”历史背景；其关于当前会话固定七步和九项任务的表述由本 ADR 取代。
- `docs/decisions/0006-phase-a-semantic-types-and-non-echo-evidence.md` 的语义类型、唯一未知量和非回显原则继续有效，但不再要求这些原则必须嵌入三个独立问题的固定页面结构。
